# HA-Plugins-sidebar-navigator

Full-power project and session navigator for Hermes Desktop. Bypasses the 3-session sidebar overview limit and gives you smooth, scrollable, searchable access to all conversations.

## Installation
The plugin is deployed directly to:
```bash
~/.hermes/desktop-plugins/ha-sidebar-navigator/plugin.js
```
Open Hermes Desktop, press `Cmd/Ctrl + K` and run **Reload desktop plugins**.
